# فلوسي 3.0 — مديرك المالي الشخصي

تطبيق ويب تقدمي (PWA) عربي يعمل على الآيفون والأندرويد والكمبيوتر، دون إنترنت ودون إنشاء حساب.
الرابط: https://basselmonaser-cloud.github.io/folosi/

## بنية المشروع
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الواجهة |
| `css/app.css` | التصميم (فاتح/داكن/تلقائي) |
| `js/core.js` | المنطق المالي: الأرصدة، التحويلات، الدفعات، العملات، التقارير، الترحيل |
| `js/store.js` | الحفظ المحلي (IndexedDB + localStorage) بنفس مفاتيح الإصدارات السابقة |
| `js/security.js` | القفل والتشفير وFace ID ومفتاح الاسترداد والنسخ المشفرة |
| `js/fx.js` | أسعار الصرف |
| `js/drive.js` | Google Drive الاختياري |
| `js/config.js` | معرف Google OAuth (فارغ = الميزة مخفية) |
| `js/app.js` | الواجهة |
| `sw.js` | العمل دون إنترنت والتحديثات |
| `tests/` | الاختبارات الآلية |

لا توجد أي مكتبات خارجية وقت التشغيل ولا خطوة بناء: الملفات تُرفع كما هي.

## الاختبارات (للمطور)
```
npm install
npm test            # اختبارات المنطق والتشفير
npm run test:e2e    # اختبارات المتصفح (Chromium)
```

## عند إصدار تحديث
غيّر `VERSION` في `sw.js` و`APP_VERSION` في `js/core.js` ثم ارفع الملفات. تظهر للمستخدمين رسالة «يتوفر تحديث جديد».
