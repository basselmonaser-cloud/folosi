# فلوسي 2.0 — إصدار تجريبي للاختبار

## طريقة النشر
1. صدّر نسخة JSON من التطبيق القديم **قبل** استبدال الملفات.
2. افتح مستودع GitHub العام `basselmonaser-cloud/folosi`.
3. ارفع محتويات هذا المجلد **مباشرة إلى جذر المستودع** (index.html, app.js, sw.js, manifest.webmanifest, icons/) ولا ترفع المجلد نفسه كطبقة إضافية.
4. استبدل الملفات القديمة، وأضف `app.js` الجديد.
5. انتظر نشر GitHub Pages، ثم افتح https://basselmonaser-cloud.github.io/folosi/ وتأكد من ظهور v2.0.
6. جرّب بيانات اختبارية أولًا؛ لا تمسح بيانات Safari أو التطبيق القديم.

## الحفظ والترحيل
- يعمل بدون اتصال بعد أول تحميل ناجح.
- يحتفظ بنسخة محلية في localStorage وIndexedDB، مع محاولة ترحيل `folosi_v1` دون حذفه.
- الرصيد القديم يُنقل إلى حساب «رصيد النسخة السابقة (غير موزع)» ويحتاج مراجعة قبل توزيع الأرصدة؛ لا تدخل أرصدة حساباتك القديمة فوقه دون تسوية حتى لا يتكرر احتساب المال.
- التخزين المحلي قد يُحذف؛ نزّل نسخة JSON واحتفظ بها في Files أو Google Drive يدويًا حتى اكتمال المزامنة.
- **غير منفذ في هذا الإصدار:** Google Drive OAuth والمزامنة التلقائية بين الأجهزة، Face ID / PIN، إرسال بلاغات آلي وإشعارات البريد، تعديل العمليات المرتبطة بالدفعات. لا تعتمد عليه بعد كتطبيق مالي إنتاجي متعدد المستخدمين.

## تجربة القبول
- أضف حسابين ورصيدين، سجل مصروفًا، وسجل تحويلًا، وتأكد أن إجمالي الأرصدة لا يتغير بسبب التحويل.
- أضف مشروعًا، ثم دفعة جزئية، وتأكد من تغير رصيد الحساب والمستحق.
- نزّل نسخة JSON ثم استعدها على نسخة اختبارية.
- جرّب وضع الطيران بعد فتح التطبيق أول مرة.
- افتح التطبيق بعد إغلاقه وتأكد من بقاء البيانات.
