# فلوسي — تطبيق مالي قابل للتثبيت على الآيفون

## النشر مجانًا باستخدام GitHub Pages
1. أنشئ حسابًا مجانيًا على github.com، ثم مستودعًا عامًا جديدًا باسم `folosi`.
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع (ملفات `index.html` و`sw.js` و`manifest.webmanifest` ومجلد `icons`).
3. افتح Settings → Pages، واختر Deploy from a branch، ثم `main` و`/(root)` واضغط Save.
4. انتظر ظهور رابط مثل `https://USERNAME.github.io/folosi/` وافتحه من Safari على الآيفون.
5. من زر المشاركة في Safari اختر «إضافة إلى الشاشة الرئيسية» ثم «إضافة».
6. افتح فلوسي من الأيقونة؛ سيعمل دون اتصال بعد التحميل الأول، بشرط أن تكتمل عملية التخزين المؤقت.

## ربط ChatGPT المجاني
افتح تبويب ChatGPT داخل فلوسي، اختر الفترة واضغط «تجهيز التقرير» ثم «نسخ التقرير» و«فتح ChatGPT» والصق التقرير في المحادثة. لا يوجد وصول آلي أو مزامنة مباشرة بين ChatGPT والتطبيق.

## تنبيهات
- البيانات تُحفظ محليًا على هذا الجهاز وفي نطاق موقع التطبيق. لا تمسح بيانات Safari للموقع دون تصدير نسخة JSON أولًا.
- إذا نقلت التطبيق إلى رابط مختلف، لا تنتقل بياناته تلقائيًا: صدّر JSON ثم استورده على الرابط الجديد.
- GitHub Pages استضافة عامة لملفات التطبيق فقط؛ لا ترفع إليها نسخ بياناتك المالية أو مفاتيح سرية.
- زر حذف العملية المرتبطة بسداد دين قد يسبب عدم تطابق بين سجل العمليات ورصيد الدين. يفضّل تجنب حذف هذه العمليات، واستخدام نسخة احتياطية قبل التعديل.
- هذا ليس تطبيق App Store، بل PWA يثبت على الشاشة الرئيسية.
