# فلوسي 2.2 — معاينة واجهة وتحسينات التحديث

هذه حزمة تجريبية مبنية على folosi-main.zip الأصلي.

## الموجود
- مظهر فاتح وداكن وتلقائي بحسب نظام الجهاز، مع حفظ تفضيل المستخدم.
- اختصارات سريعة أعلى الرصيد يمكن إظهارها وإخفاؤها وترتيبها.
- تحديث إصدار ملفات Service Worker وتضمين interface.js في التخزين المؤقت.
- الإبقاء على مفاتيح البيانات الأصلية folosi_v2 و folosi-store دون تغيير.

## غير موجود بعد
- Face ID أو PIN مشفر.
- Google Drive OAuth والنسخ التلقائي.
- أسعار صرف حية أو حسابات متعددة العملات.
- اختبارات iPhone الفعلية أو ضمان ترحيل البيانات على جميع الأجهزة.

## قبل النشر
1. صدّر نسخة JSON من فلوسي الموجود.
2. ارفع الملفات داخل هذا المجلد إلى جذر المستودع نفسه، لا ترفع ملف ZIP نفسه.
3. لا تحذف المستودع أو التطبيق المثبت أو بيانات Safari.
4. جرّب نسخة تجريبية قبل النشر العام، وتحقق من عملياتك القديمة.
